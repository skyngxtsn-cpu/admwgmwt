# 薬局棚卸しアプリ

Google Apps Script (GAS) で動く薬局棚卸し用 Web アプリ。
スマホから医薬品を検索 → 有効期限を入力 → 棚卸し日から **18ヶ月以内**の切迫品をその場で判定し、Google スプレッドシートに記録する。

## 初回セットアップ（所要 15-20 分）

### 1. Google スプレッドシートを作成

1. ブラウザで Google ドライブを開き、新規スプレッドシート（例：「薬局棚卸し」）を作成。
2. 1枚目のシートを `医薬品マスタ` にリネーム。
3. シートを2枚追加：`棚卸し記録` / `期限一覧`（`棚卸し記録` は GAS が自動作成するため省略可）。

### 2. GAS プロジェクトをスプレッドシートに紐付ける

1. スプレッドシートの上部メニュー **拡張機能 → Apps Script** を選択。
2. 開いた GAS エディタで以下のファイルを作成し、`src/` 配下の同名ファイルの**中身をそのまま貼り付ける**：

| GAS エディタ上のファイル | コピー元 |
|--------------------------|----------|
| `appsscript.json`        | `src/appsscript.json`（左メニュー歯車「プロジェクトの設定」→「`appsscript.json` マニフェストファイルを表示する」を有効化してから編集） |
| `Code.gs`（最初から存在） | `src/Code.gs` |
| `Master.gs`（新規）       | `src/Master.gs` |
| `Inventory.gs`（新規）    | `src/Inventory.gs` |
| `Pivot.gs`（新規）        | `src/Pivot.gs` |
| `Index.html`（新規 HTML）  | `src/Index.html` |
| `Style.html`（新規 HTML）  | `src/Style.html` |
| `Client.html`（新規 HTML） | `src/Client.html` |

3. すべて貼り付けたら **保存**（⌘+S / Ctrl+S）。

### 3. 医薬品マスタを取り込む

`master/import_master.md` の手順に従って `医薬品マスタ` シートに最低6列を用意する：
**A: YJコード / B: 医薬品名 / C: カナ名 / D: 規格 / E: 単位 / F: メーカー**（1行目はヘッダ）

### 4. Web App としてデプロイ

1. GAS エディタ右上 **デプロイ → 新しいデプロイ**。
2. 種類：**ウェブアプリ**。
3. 設定：
   - 説明：`薬局棚卸し v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
4. **デプロイ** → 初回は権限の許可ダイアログが出るので承認。
5. 表示された **ウェブアプリ URL** をコピー。
6. スマホでその URL を開き、ブラウザの「ホーム画面に追加」でショートカット化。

## 使い方

1. ヘッダの「棚卸し日」を確認（デフォルトは今日、変更可）。
2. 検索欄に薬品名・カナ・YJコードのいずれかを2文字以上入力。
3. 候補リストから該当をタップで選択。
4. 有効期限（YYYY/MM）と数量・棚位置・メモを入力。
5. **記録する** ボタン → トーストで判定結果が出る：
   - 🛑 **期限切れ**（過去）
   - ⚠️ **切迫品**（棚卸し日から18ヶ月以内）
   - ✅ **OK**（18ヶ月超）
6. **期限一覧シートを更新** ボタンで `期限一覧` シートを再構築。
   行=薬品、列=期限月のピボット形式。18ヶ月以内の列は薄赤、過去は薄グレー。

## 切迫品の閾値を変えたいとき

`Inventory.gs` 冒頭の定数 `IMPENDING_MONTHS` を変更（例：`12` で12ヶ月）。
GAS エディタで保存後、ブラウザでページをリロードすれば即反映。

## 既知の制約

- iOS Safari の `<input type="month">` はピッカーが簡素。月単位入力なので運用上は問題なし。
- 医薬品マスタが2万件超で `CacheService` の100KB制限を超える場合、キャッシュは無視され毎回シート読込になる（数百ms 増程度）。
- Web App URL は本人のみアクセス可。他人と共有するには「アクセスできるユーザー」を変更（ただし機密性に注意）。
